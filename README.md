# 🔬 AI Research Studio

AI Research Studio is a multi-agent AI research application that helps users research a topic, analyze information, verify important claims, and generate a structured research report.

The application uses AI and web search to automate different stages of the research process and provides a downloadable PDF report.

## 🚀 Features

- 🔎 Web-based research using DuckDuckGo Search
- 🤖 Multi-agent AI workflow
- 📊 Research analysis
- ✅ Fact-checking of important claims
- 📝 Automatic report generation
- 📄 Download research reports as PDF
- 🌐 Interactive Streamlit web interface

## 🔄 Workflow

The application follows a multi-agent workflow:

1. **Research Agent**
   - Searches the web for relevant information.
   - Collects sources and important facts.

2. **Analysis Agent**
   - Analyzes the collected research.
   - Identifies trends, benefits, challenges, risks, and opportunities.

3. **Fact Checker Agent**
   - Reviews important claims.
   - Checks whether claims are supported by the available sources.

4. **Report Writer Agent**
   - Combines the research, analysis, and fact-checking results.
   - Generates a structured research report.

5. **PDF Generator**
   - Converts the generated report into a downloadable PDF.

⚙️ Installation
1. Clone the repository
git clone https://github.com/SagnikDas007/AI-Research-Studio.git
2. Open the project folder
cd AI-Research-Studio
3. Install the required packages
pip install -r requirements.txt
4. Create the .env file

Create a .env file in the project directory:

GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=openai/gpt-oss-20b

Replace your_groq_api_key with your actual Groq API key.

5. Run the application
streamlit run app.py

The application will open in your browser.

🔐 Environment Variables

The application requires the following environment variables:

Variable	Description
GROQ_API_KEY	API key used to access the Groq AI service
GROQ_MODEL	Groq model used by the application

The .env file is excluded from GitHub using .gitignore.
